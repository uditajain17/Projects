## Project Overview
 
This project analyses Superstore sales data using Microsoft Excel.
 
The dashboard helps understand sales performance, profit, customer behaviour, product categories, regions and business trends.
 
## Tools Used
 
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
 
## Key Business Questions
 
- Which region generates the highest sales?
- Which product category generates the highest profit?
- Which products perform well?
- Which customer segments contribute the most to sales?
- How do sales change over time?
 
## Dashboard Features
 
- Sales analysis
- Profit analysis
- Category-wise analysis
- Region-wise analysis
- Customer segment analysis
- Interactive filters and slicers
